# Fattoush Fine Dining

Build a Premium Restaurant Website for Fattoush Restaurant & Banquet

Create a premium, elegant, animated, illustrative and fully responsive restaurant website for:

Fattoush Restaurant & Banquet

Cuisine: Middle Eastern / Multi-Cuisine
Location: 425/1A, Nookampalayam Link Rd, Alamelu Manga Puram, Sholinganallur, Chennai, Tamil Nadu 600119

The website should feel like a high-end modern Middle Eastern restaurant brand, not like a generic restaurant template.

The design must be:

Food-focused

Visually rich

Elegant

Create a luxurious visual identity inspired by:

Middle Eastern architecture

Use a combination of:

subtle gold accents

Avoid excessive gold. The gold should be used only as a premium accent.

Suggested palette:

Background: #12100E

2. TYPOGRAPHY

Use an elegant serif font for major headings.

Suggested:

Headings: Playfair Display / Cormorant Garamond

Body: Inter / Manrope

Small labels: Inter with increased letter spacing

Large headings should be dramatic but not oversized to the point of being difficult to read.

Use uppercase small labels such as:

"AUTHENTIC FLAVOURS"
"FROM OUR KITCHEN"
"THE FATToush EXPERIENCE"

24. RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:
1440px+

Tablet:
768px–1199px

Mobile:
320px–767px

On mobile:

Navigation becomes hamburger

Hero typography scales down

Food cards become horizontal/stacked

Gallery becomes 2-column or single-column

Buttons become thumb-friendly

Map scales properly

Text remains readable

No horizontal scrolling

25. PERFORMANCE

Despite being visually rich, the website must remain fast.

Use:

Lazy-loaded images

Optimized WebP/AVIF images

Responsive image sizes

CSS transforms for animations

GPU-friendly animations

Avoid unnecessary JavaScript

Avoid huge video files

Preload only critical hero assets

Do not sacrifice performance for animation.
